
# Royal Electronics

A complete website for a electronics repair shop, offering device repair services and products.

## What technologies are used for this project?

This project is built with:

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
- React Router

## Features

- Responsive design optimized for all devices
- Interactive UI elements with animations
- Booking system for repair services
- Product catalog
- Contact form
- Testimonials

## Pages

- **Home**: Landing page with services, featured reviews, and call to action
- **Products**: Display of available products and repair kits
- **About**: Company information and customer testimonials
- **Contact**: Contact information and message form
- **Booking**: Appointment scheduling form for repair services
